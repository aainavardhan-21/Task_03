# Task_03
# CSS Selectors Assignment

## 📌 Description
This project is a CSS Selectors assignment created as part of the MERN Stack course. It demonstrates the use of different CSS selectors to style HTML elements without relying heavily on inline CSS.

## ✨ Features
- Set background color using CSS
- Styled headings using class selectors
- Styled a heading using an ID selector
- Styled specific words using the `<span>` tag
- Styled paragraphs using element selectors
- Used ordered and unordered lists
- Applied CSS pseudo-class selectors (`:first-child`, `:last-child`, `:nth-child()`)

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Run
1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📖 Learning Outcomes
- Understanding CSS selectors
- Using class and ID selectors
- Styling specific elements with descendant and child selectors
- Using pseudo-class selectors
- Organizing HTML and CSS files
